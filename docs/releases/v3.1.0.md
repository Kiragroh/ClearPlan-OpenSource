# ClearPlan v3.1.0

ClearPlan v3.1.0 is the simulator-backed technical-note release. It provides a
patient-free way to inspect the integrated plan-review interface and preserves
a separate locally built Eclipse/ESAPI mode.

## Highlights

- Vendor-free Windows x64 simulator with seven deterministic synthetic
  scenarios
- Integrated overview plus focused PQM, PlanCheck, field-name, and wide DVH
  pages
- Read-only field-ID and PlanFieldNamer-compatible name conformance, including
  couch-before-direction ordering such as `179-181 T30 UZ`
- RefDB JSON and Excel workbook sources normalized into one validated catalog
- Bounded optional network-source loading and last-valid workspace retention
- Versioned neutral `ReviewSnapshot` used by the simulator and Eclipse host
- Illustrative, unvalidated, read-only RayStation adapter example
- Reproducible ZMP Short Communication manuscript, three synthetic figures,
  and machine-readable evidence
- Proposed local commissioning scaffold that clearly separates public
  regression fixtures from site-specific clinical acceptance

## Start modes

The attached `ClearPlan-Simulator-v3.1.0-win-x64.zip` runs without Eclipse,
ESAPI, proprietary TPS assemblies, or patient data. Start
`ClearPlan.Simulator.exe` and select a scenario, or pass
`--scenario mixed-review`.

The Eclipse/ESAPI runner remains a separate local build. It requires
institution-approved vendor assemblies, a locally commissioned constraint
catalog and PlanCheck implementation, and site-specific validation. Licensed
vendor assemblies are not included in this release.

The RayStation adapter under `examples/raystation` is an illustrative contract
example only. It has not been runtime-validated or clinically commissioned.

## Evidence boundary

All results in the technical note are deterministic and synthetic. This
release does not establish clinical sensitivity, specificity, false-positive
rate, workflow efficiency, error reduction, or patient-safety benefit.

The `.sha256` asset contains the SHA-256 checksum of the simulator archive.
