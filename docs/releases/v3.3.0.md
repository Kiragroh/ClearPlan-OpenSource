# ClearPlan v3.3.0

**Released 25 November 2026.** [GitHub release](https://github.com/Kiragroh/ClearPlan-OpenSource/releases/tag/v3.3.0).
This is not a clinical installer and not clinical commissioning.

This version accompanies the Short Communication "Configurable plan review and
reporting through treatment planning system scripting". It combines two lines
that were developed separately:

1. **Verified review line (phantom verification, 29 October 2026).** Structured
   review log with five linked tables, pseudonymised identifiers, rule-set
   fingerprints and SHA-256 of the written report (`docs/REVIEW_LOG.md`).
   It also includes the SQLite importer and example views (`tools/review-log/`),
   retrospective evaluation with the same rules (`tools/review-log/mining/`),
   and the RayStation example adapter with its tests (`examples/raystation/`).
2. **Revised review interface (20 November 2026).** Navigation grouped by task,
   status chips and summary tiles, consistent spacing and English texts. The
   dose views are fitted to a chosen isodose (default 20%) plus 1 cm. The BEV
   offers DRR, PTV-contour and MLC-only modes, and the collimator is shown at
   its planned angle. In the collision view, the MLC opening can follow the
   arc. A DVH statistics table (volume, Dmin, D98, D50, Dmean, D2, Dmax) is
   shown in the interface and in the PDF report. Display preferences can be
   stored globally and per user. A sandbox mode reads a stored snapshot of a
   test plan, with MU deliberately perturbed and marked as non-clinical.

## What was checked

- Portable tests: 517 passed (`ClearPlan.Core.Tests`), RayStation example
  93 passed (5 skipped), review-log importer 2 passed. The 8 end-to-end importer
  tests need an exported example log via `CLEARPLAN_REVIEW_LOG_EXAMPLE`.
- Native phantom verification (two physical-phantom plans, read-only): see
  Supplement S4 of the manuscript.
  - The revised interface was run with the verification configuration on both
    plans. Goal entries, plan-parameter values and check findings were
    identical to the verified build.
  - Only the collision illustration images and one new display-only field
    differed.
- The phantom reports in the manuscript supplement contain physical-phantom
  data only.

## Not included

- Local configuration, credentials, clinical rule sets and proprietary TPS
  assemblies.
- The sandbox snapshot file, which stays local.
